# Sotto 0.1.33

This release improves keyboard navigation and correction handling during
transcript review.

- Command/Ctrl+F opens the Transcript tab and focuses its search field, including
  when starting from the meeting summary.
- Enter advances through matching segments, Shift+Enter moves backward, and Esc
  clears the search. Repeating Find selects the existing query for replacement.
- Opening another segment editor is disabled until the current correction is
  saved or cancelled, preventing accidental replacement of an unfinished draft.
- Command/Ctrl+Enter saves a correction; Esc cancels it. Both return keyboard
  focus to the segment's Edit button. Empty and unchanged corrections are not
  submitted, and failed saves keep the editor open.
- Updates the development dependencies `fast-uri` to 3.1.7 and `@xmldom/xmldom`
  to 0.9.12 to address their current audit findings.

The release uses the existing macOS Apple Silicon distribution workflow:
source checks, pinned native runtime, Developer ID signing, Apple notarization,
mounted-DMG verification, SHA-256 checksums, and GitHub provenance attestations.
Windows remains a source-tested development target, without a public installer.
